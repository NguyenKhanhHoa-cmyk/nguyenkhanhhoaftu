### CÁCH 1: Tải trực tiếp qua trình duyệt web (Dành cho mọi người)

#### Bước 1: Tạo Repository trên GitHub
1. Truy cập [github.com](https://github.com) và đăng nhập (hoặc đăng ký tài khoản miễn phí).
2. Nhấn vào dấu **`+`** ở góc trên bên phải màn hình -> Chọn **New repository**.
3. Điền thông tin:
   - **Repository name**: ví dụ `himym-portfolio` (hoặc `khanhhoa-cv`).
   - Chọn chế độ: **Public** *(Bắt buộc chọn Public để dùng GitHub Pages miễn phí)*.
   - Các ô khác có thể để trống.
4. Nhấn nút xanh **Create repository**.

#### Bước 2: Tải toàn bộ các file lên GitHub
1. Trong trang kho vừa tạo, tìm dòng chữ *"uploading an existing file"* (hoặc nút **Add file** -> **Upload files**).
2. Kéo và thả toàn bộ các file và thư mục từ `C:\Users\ramkr\.gemini\antigravity\scratch\himym-portfolio`:
   - `index.html` *(Bắt buộc ở thư mục gốc)*
   - `style.css`
   - `app.js`
   - `himym_intro.mp4` *(Video mở màn)*
   - `khanhhoa.jpg` *(Ảnh chân dung)*
   - Thư mục `assets/` *(chứa logo và ảnh cast)*
   - `README.md`
   - `cv_updated.md`
3. Kéo xuống dưới cùng và nhấn nút xanh **Commit changes**.

#### Bước 3: Bật tính năng GitHub Pages
1. Tại trang repository của bạn, nhấn vào tab **Settings** (biểu tượng bánh răng ở thanh menu trên).
2. Ở cột menu bên trái, cuộn xuống phần *Code and automation*, nhấn vào **Pages**.
3. Tại mục **Build and deployment**:
   - **Source**: Chọn `Deploy from a branch`.
   - **Branch**: Chọn `main` (hoặc `master`), thư mục giữ nguyên `/ (root)`.
4. Nhấn **Save**.

#### Bước 4: Nhận link xem website trực tiếp
- Sau khoảng 1 đến 2 phút, hãy làm mới lại trang Settings -> Pages.
- Bạn sẽ thấy dòng chữ xanh:
  > **"Your site is live at https://<your-username>.github.io/himym-portfolio/"**
- Nhấn vào link đó để thưởng thức portfolio của bạn hoạt động trên Internet!

### CÁCH 2: Xuất bản bằng dòng lệnh Git (Dành cho Lập trình viên)

Mở **PowerShell** hoặc **Terminal** tại thư mục dự án và chạy:

```bash
# 1. Chuyển vào thư mục chứa portfolio
cd "C:\Users\ramkr\.gemini\antigravity\scratch\himym-portfolio"

# 2. Khởi tạo Git repository
git init
git add .
git commit -m "feat: HIMYM Yellow Umbrella Portfolio with authentic intro video"

# 3. Đổi tên nhánh sang main
git branch -M main

# 4. Thêm remote GitHub của bạn (thay <USERNAME> bằng tên tài khoản của bạn)
git remote add origin https://github.com/<USERNAME>/himym-portfolio.git

# 5. Đẩy toàn bộ code lên GitHub
git push -u origin main
```

Sau đó vào **Settings** -> **Pages** trên GitHub và chọn branch `main` tương tự như Bước 3 ở Cách 1.
